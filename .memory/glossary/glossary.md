# Glossary

| Term | Definition |
|---|---|
| **Alis** | Cross-platform C# game framework |
| **AOT** | Ahead-of-time compilation — compatibility required (no Reflection.Emit) |
| **Aspect** | Layer 5 — cross-cutting concerns and contract interfaces |
| **BroadPhase** | Spatial partitioning for collision detection |
| **Bounded Context** | DDD term for a specific domain boundary |
| **CQRS** | Command Query Responsibility Segregation |
| **CSPROJ** | C# project file |
| **Declaration** | Layer 5 — aspect-oriented contracts |
| **ECS** | Entity Component System — gameplay programming model |
| **GJK** | Gilbert-Johnson-Keerthi distance algorithm |
| **Ideation** | Layer 6 — foundation layer with core data types |
| **MediatR** | .NET library for CQRS/mediator pattern |
| **MSBuild** | Microsoft build engine |
| **NuGet** | .NET package manager |
| **Operation** | Layer 4 — engine subsystems (Audio, ECS, Graphic, Physic) |
| **P/Invoke** | Platform Invocation Services — calling native APIs from .NET |
| **Presentation** | Layer 1 — user-facing applications |
| **RID** | Runtime Identifier (e.g., osx-arm64, win-x64) |
| **Roslyn** | .NET compiler platform (used for source generators) |
| **SIMD** | Single Instruction Multiple Data — CPU vectorization |
| **SLNX** | Solution XML file format |
| **Structuration** | Layer 3 — core abstractions |
| **TFM** | Target Framework Moniker (e.g., net8.0, netstandard2.0) |
