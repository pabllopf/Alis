# System Results Index

## Overview

This directory contains one-off analysis results and tool outputs from previous repository analysis sessions. These are cached results from automated analysis tools.

## Contents

The directory contains 100+ result files from:
- Code analysis runs
- File inspection outputs
- Tool-generated reports
- Cached analysis data

## Notes

- These files are cached outputs from analysis tools
- They may be regenerated by re-running the corresponding analysis
- Some results may be stale if source code has changed
- The `.memory/system/cache/` directory contains related cached data
