# Alis.Sample.Empty

## Overview

Absolute minimal bootstrap sample: `VideoGame.Create().Run()` with no settings, no world, no components.

## Properties

| Property | Value |
|---|---|
| **Type** | Sample Game |
| **Path** | `2_Application/Alis/samples/alis.sample.empty/` |
| **Framework** | net10.0 |
| **Output Type** | Exe (AOT published) |

## Structure

- Single `Program.cs` file
- Namespace: `Alis.Sample.Empty.Desktop`
- No custom components
- No scenes

## Usage

Demonstrates the simplest possible Alis engine bootstrap.
