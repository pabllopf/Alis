# Alis.Sample.Dino

## Overview

T-Rex Dino Game stub sample. Minimal setup demonstrating the basic engine bootstrap with named settings and audio configuration.

## Properties

| Property | Value |
|---|---|
| **Type** | Sample Game |
| **Path** | `2_Application/Alis/samples/alis.sample.dino/` |
| **Framework** | net10.0 |
| **Output Type** | Exe (AOT published) |

## Structure

- Single `Program.cs` file
- Scene with a "Sound Track" GameObject
- Resolution: 800x600
- Gravity enabled
- No custom components

## Usage

Serves as a starting template for new game projects.
