# Document Template

## Overview

Standard template for Alis memory system documents.

## Frontmatter

```yaml
---
```

## Sections

### Required
- **Overview**: Brief description of the topic
- **Related**: Wiki-links to related documents

### Optional
- **Details**: In-depth information
- **Architecture**: Structural diagrams
- **Examples**: Code examples
- **References**: External references
